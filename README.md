# Eng2Kor Flow - 영한 자동 변환

한/영 키를 깜빡하고 영문 자판으로 친 한글을 입력 중에 자동으로 바꿔 주는 크롬 확장입니다.

```
dkssudgktpdy  →  안녕하세요
```

- 스페이스, Enter, 문장부호를 칠 때 바로 앞 단어를 바꿉니다.
- 숫자에 붙여 친 단위와 조사도 바꿉니다(5ro → 5개). 16gb, 4th처럼 영어 단위와 겹치는 것은 그대로 둡니다.
- 첫 글자만 대문자인 단어(Clairaut 등)는 영어 이름으로 보고 바꾸지 않습니다. 쌍자음과 ㅒ, ㅖ를 치는 Q, W, E, R, T, O, P로 시작하면 예외입니다.
- 치는 동안 단어가 무엇으로 바뀔지 커서 아래 말풍선으로 미리 보여 줍니다. 받침이 다음 글자로 넘어갈지 모르는 낱자는 흐리게 표시합니다. 팝업에서 끌 수 있습니다.
- 말풍선이 떠 있을 때 Tab을 누르면 자동완성처럼 그 내용으로 바꾸고 커서는 그 자리에 둡니다. 말풍선이 없거나 낱자가 흐리게 남아 있으면 Tab은 원래대로 동작합니다.
- 바뀐 직후 Backspace를 누르면 원래 글자로 돌아갑니다. 스페이스로 바뀐 경우에는 첫 Backspace가 공백만 지우고, 이어서 한 번 더 누르면 돌아갑니다.
- 되돌린 단어는 그 자리에 그대로 둡니다. 글자를 고쳐 치거나 같은 단어를 나중에 다시 치면 다시 바꿉니다.
- 비밀번호 칸에서는 동작하지 않습니다. 입력 내용은 저장하거나 전송하지 않습니다([개인정보처리방침](store/privacy.md)).

## 개발

크롬 `chrome://extensions`에서 개발자 모드를 켜고 `extension` 폴더를 "압축해제된 확장 프로그램"으로 불러옵니다.

```bash
node --test                        # 테스트
powershell -File scripts/pack.ps1  # 스토어 업로드용 zip
```

`node --test`는 크롬을 찾으면 `test/browser.test.mjs`도 돌립니다. 헤드리스 크롬에 실제 키 입력을 보내 input, textarea, contenteditable과 자체 모델 편집기 흉내(`test/editors.html`)에서 괄호와 문장부호 변환, 빠른 연속 입력, Backspace 복원을 확인합니다. 크롬 경로는 `CHROME` 환경 변수로 줄 수 있고, 찾지 못하면 건너뜁니다. Slate 항목은 esm.sh에 접속할 수 있을 때만 돕니다.

## 알려진 한계

- 두벌식 자판 기준입니다.
- 구글 문서는 아직 지원하지 않습니다(다음 버전 예정).
- 비밀번호 판정은 type, autocomplete, 마스킹 스타일, name/id 신호가 있는 입력칸만 보장합니다.
- Gmail, ChatGPT, Claude에서는 Ctrl+Z가 변환과 그 앞의 입력을 한 번에 되돌릴 수 있습니다.
- 변환용 `beforeinput`을 취소만 하고 반영하지 않는 편집기와, 스크립트가 보낸 입력을 무시하는 Slate(slate-react 0.128~0.132)에서는 바꾸지 않고 친 글자를 그대로 둡니다.
- `beforeinput`을 받아들이지 않으면서 DOM 변경도 따라가지 않는 자체 모델 편집기는 화면과 내용이 어긋날 수 있습니다. 문제가 있는 사이트는 팝업에서 끌 수 있습니다.
