# 스토어 등록 정보

## 이름
Eng2Kor Flow - 영한 자동 변환

## 짧은 설명 (132자 이내)
한/영 전환을 깜빡하고 영문으로 친 한글을 입력 중에 자동으로 바꿔 줍니다. dkssud → 안녕. 입력 내용은 저장하거나 전송하지 않습니다.

## 상세 설명
한/영 키를 누르는 걸 깜빡하고 "dkssudgktpdy"를 쳐 버린 적 있으신가요?
Eng2Kor Flow는 영문 자판으로 친 한글을 스페이스나 Enter를 누르는 순간 "안녕하세요"로 바꿔 줍니다.

■ 이렇게 동작해요
• 입력하는 도중 자동 변환: dkssud → 안녕, dho go → 왜 해, rmfozzz → 그래ㅋㅋㅋ, 5ro → 5개
• 바뀔 글자 미리보기: 치는 동안 단어가 무엇으로 바뀔지 말풍선으로 보여 줘요. 말풍선이 떠 있을 때 Tab을 누르면 바로 바꿔요(팝업에서 끌 수 있어요)
• 영어는 그대로: hello, meeting, git push 같은 영어 단어는 바꾸지 않아요
• 잘못 바뀌면 백스페이스로 되돌리기: 원래 영문으로 돌아가요. 스페이스로 바뀐 경우엔 첫 백스페이스가 공백만 지우고, 한 번 더 누르면 돌아가요
• 검색창, 댓글창, 메일, 메신저 입력창 등 대부분의 입력칸에서 동작해요
• Colab 노트북의 텍스트 셀과 코드 셀(주석, 문자열 안)에서도 동작해요
• 사이트별로 끄거나 전체를 끌 수 있어요

■ 개인정보
• 바꿀 때를 알기 위해 입력칸의 키 입력과 커서 바로 앞 단어를 읽습니다
• 입력 내용은 기기 안에서만 처리하며 어디에도 저장하거나 전송하지 않습니다
• 비밀번호로 표시된 입력칸은 읽지 않습니다
• 저장하는 것은 켜기/끄기 설정과 꺼 둔 사이트 목록뿐입니다

■ 알려진 한계
• 두벌식 자판 기준입니다
• 구글 문서처럼 자체 입력 방식을 쓰는 일부 편집기에서는 동작하지 않습니다

## 단일 목적
영문 자판 상태에서 입력된 두벌식 한글 키 입력을, 사용자가 입력하는 도중 한글로 변환합니다.

## 권한 사용 사유
- storage: 자동 변환, 변환 미리보기 켜기/끄기 설정과 사용자가 끈 사이트 목록을 저장합니다.
- 호스트 권한(모든 http/https 사이트의 콘텐츠 스크립트): 사용자가 방문하는 웹사이트의 입력칸에서 따로 조작하지 않아도 자동으로 변환하는 것이 이 확장의 유일한 기능입니다. 이를 위해 모든 사이트에서 입력칸의 키 입력을 감지해야 합니다. 입력 내용은 기기 안에서만 처리하며 저장하거나 전송하지 않습니다.

## 원격 코드
사용하지 않습니다. 모든 코드는 확장 패키지에 포함되어 있습니다.

## 데이터 사용 공시
기기 안에서만 처리하는 데이터도 공시해야 한다(웹스토어 사용자 데이터 FAQ 3번).
- 웹사이트 콘텐츠: 체크. 입력칸에서 커서 바로 앞 단어를 읽는다.
- 사용자 활동: 체크. 변환 시점을 정하려고 키 입력을 감지한다(기록하지 않음).
- 개인 커뮤니케이션: 체크. 메일, 메신저 작성란에서도 커서 앞 단어를 읽는다.
- 그 밖의 항목(개인 식별 정보, 건강, 금융, 인증, 위치, 웹 기록): 체크하지 않음. 비밀번호 칸은 읽지 않는다.
- 제3자 판매, 양도 / 단일 목적과 무관한 사용 / 신용도 판단, 대출 목적 사용: 하지 않음
- 제한적 사용 준수 문구는 개인정보처리방침에 있다(README에서 한 번에 연결됨).
- 개인정보처리방침, 대시보드 공시, 실제 동작이 서로 어긋나면 정책 위반이므로 셋을 함께 고친다.
