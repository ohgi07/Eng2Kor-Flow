# Eng2Kor Flow 개인정보처리방침

작성일: 2026-10-09 (2026-10-10 수정)

Eng2Kor Flow(이하 "확장")는 영문 자판으로 입력된 두벌식 한글 키 입력을 한글로 바꿔 주는 크롬 확장입니다.

## 처리하는 정보
- 확장은 메일, 채팅 작성란을 포함한 웹페이지 입력칸에서 커서 바로 앞의 단어를 읽어, 한글로 바꿀지 판단하고 바뀔 글자를 미리 보여 줍니다.
- 바꿀 때를 알기 위해 입력칸에서 누르는 키(스페이스, Enter, 문장부호, Backspace 등)를 감지합니다. 키 입력을 기록하거나 모아 두지 않습니다.
- 이 처리는 사용자의 기기 안에서만 이루어집니다. 입력 내용은 저장하지 않으며, 개발자나 제3자에게 전송하지 않습니다.
- 비밀번호로 표시된 입력칸(type=password, 비밀번호 자동완성 속성, 글자 가림 스타일, 이름에 pass나 pwd가 포함된 칸)은 읽지 않습니다.
- 방금 바꾼 단어(원문과 변환 결과)는 백스페이스로 되돌릴 수 있도록 다음 키를 누를 때까지만 메모리에 둡니다.
- 사용자가 백스페이스로 되돌린 단어는 같은 자리에서 곧바로 다시 바뀌지 않도록 메모리에 잠시 기억했다가, 다른 단어를 입력하거나 입력 위치를 옮기거나 클릭하면 잊습니다.

## 저장하는 정보
- 자동 변환, 변환 미리보기 켜기/끄기 설정과 사용자가 끈 사이트 목록만 크롬 저장소(chrome.storage.sync)에 저장합니다.
- 크롬 동기화가 켜져 있으면 이 설정은 사용자의 구글 계정을 통해 다른 기기와 동기화될 수 있습니다.

## 제3자 제공
확장은 어떤 정보도 판매하거나 제3자에게 제공하지 않습니다.

## Chrome 웹스토어 사용자 데이터 정책
확장이 사용자 데이터를 쓰는 방식은 제한적 사용(Limited Use) 요건을 포함한 Chrome 웹스토어 사용자 데이터 정책을 따릅니다. 입력 내용은 영문 자판으로 친 한글을 바꾸는 데에만 쓰며, 광고, 판매, 신용 평가 같은 다른 목적에 쓰거나 사람이 읽게 하지 않습니다.

The use of user data by this extension adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.
